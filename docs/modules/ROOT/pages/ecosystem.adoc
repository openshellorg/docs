= Ecosystem
:description: How OpenShellOrg documentation on this hub is partitioned.

The docs site is a small set of overlapping partitions: this hub (*open-shell-org*), *shell-architecture*, the shared *tools* component for installable OSO CLIs and libraries, and external cousins (PlayTime, DevCentr, desktop products) that are linked but not assembled here.

* xref:open-shell-org::index.adoc[open-shell-org] — SOS certification and this hub
* xref:shell-architecture::index.adoc[shell-architecture] — structured-shell thesis and layers
* xref:shell-architecture::entrypoint-dispatch.adoc[Entrypoint Dispatch] — auto-install + re-exec at the shell boundary
* xref:shell-architecture::tool-run-diagnostics.adoc[Tool runs and diagnostics] — compilers as structured runs (bus + daemon + embed library)
* xref:shell-architecture::command-channels.adoc[Command channels] — per-command stdout/stderr switcher

* xref:philosophy.adoc[Philosophy]

== Partner filesystem model

link:https://github.com/AMDphreak/connectome-fs[connectome-fs] owns node/edition/projection semantics. Shell-architecture consumes that contract for navigation; it does not redefine SOS as a filesystem query language.

* link:https://amdphreak.github.io/connectome-fs/manual/connectome-fs/0.1/explanation/shell-query-surface.html[Shell query surface]

== Tools

Installable OSO CLIs and companion libraries documented on this hub share one Antora component (`tools`). Landing page: xref:tools::index.adoc[Tools].

=== Companion libraries

* xref:tools:nu-require:index.adoc[nu-require] — require / relaunch under Nushell
* xref:tools:nu-emit:index.adoc[nu-emit] — emit structured JSONL rows from C
* xref:tools:project-map:index.adoc[project-map] — project-type + file-role classification; grouped directory listing (not a PATH `ls` replacement)
* https://github.com/openshellorg/config-lifecycle[config-lifecycle] — classify / match / alert for config keys (`active` / `deprecated` / `expired` / `unknown`); never drop expired detection — xref:standard-config-lifecycle-management.adoc[Config Lifecycle Management]

== PlayTime (cousin, not a component here)

Dev-Centr's PlayTime engine plays CentrMark playbooks and spawns **argv** (no shell costume). That stance belongs next to Entrypoint Dispatch. The engine is not in this hub yet -- do not move it mid-build.
