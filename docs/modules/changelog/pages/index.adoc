= Changelog

== Unreleased

* Build: `@antora-supplemental/facto-stack` **v0.4.0**, which brings `antora-search-chat` **v0.1.25** (readable search dropdown in dark mode; light mode unchanged) and runs the built-in contrast check (`contrast-check-v0.3.0`) on every build in light and dark mode with the search results open. The build fails on dark-mode and search-state WCAG AA errors; other findings are reported only. No workflow change.
* UI: Valentus **v4.3.1**. The current page in the breadcrumb is no longer underlined.
* Changelog: moved from the root `CHANGELOG.adoc` into the `changelog` module of the `open-shell-org` component (xref:changelog:index.adoc[Changelog] in the nav). Detail reports and saved prompts go under `changelog-details/history/`.
* Concept page NS-6: the resolver command is literally `install`; install(1) lives at `legacy/install` with a PROVISIONAL passthrough.
* New xref:ROOT:standard-cli-help.adoc[CLI Help] standard (CH-1 to CH-24), based on prohelp: `--help`, `-h` and `help` (as a command for tools with subcommands) must print help; bare invocation; progressive content and line budgets; an authored prohelp document as the source of truth, rendered through `prohelp.intercept` and gated by `prohelp check --strict`; subcommand help; help on stdout with exit 0, error help on stderr with exit 2; text subtree dump and (provisional) JSON help; did-you-mean ties to CD-1. Lists the features prohelp 0.2.3 still needs. Listed under The Standard next to CLI Dispatch; CLI Dispatch CD-1, CD-5, CD-6, CD-8 and CD-16 link to the CH rules; CLI Dispatch conformance gains help self-test rows.
* UI: Valentus **v4.3.0** and `@antora-supplemental/facto-stack` **v0.3.1** (mermaid-client / diagram-lightbox `-v0.2.2` tags). The hub fixes moved upstream, so the hub copies are gone: `site-inline-title-code.css`, `site-nav-column-scroll.css`, `site-math.js`, `site-toc-main-article.js`, `in-site-nav-tree.js` and the `breadcrumbs.hbs` override. The breadcrumb component filter is now the Valentus opt-in site key `valentus_bc_components: site-nav-tree`. `head-meta.hbs` is resynced to Valentus 4.3.0 plus the hub additions.
* Playbook: the `ns` tool is renamed `name` (repo openshellorg/name). Concept page NS-2 notes JSON5 manifests; NS-7 records the decided `+` free-flag sigil.
* Playbook: add the Tools components from command-namespace, ns, install, versions and isolate.
* New proposed concept page xref:ROOT:concept-command-namespace.adoc[Command namespace and context requests] (NS-1 to NS-14): hierarchical command namespace instead of PATH, input signatures for context requests (current folder as declared input), fixed-height composition area, isolation levels (overlay, fence, partition, guest). Listed under Concepts (proposed) in the nav.
* New xref:ROOT:standard-cli-dispatch.adoc[CLI Dispatch] standard (CD-1 to CD-12): unknown commands are usage errors (stderr, exit 2, did-you-mean); no implicit catch-all for bare words; documented and announced bare-invocation defaults (help preferred); no-argument tools and GUI launchers reject any input; wrappers forward only known commands and name the tool that implements the rest; mandatory migration (warn on every implicit use plus strict opt-in now, strict by default next major). Non-normative note on CLI styles, worked dub/redub example and conformance checklist. Listed under The Standard in the nav and cross-linked from xref:ROOT:standard-cli-output.adoc[CLI Output].
* Float `@antora-supplemental/facto-stack` on rolling minor git pin **`#v0.2`** (resolves **v0.2.64** today).
* New xref:ROOT:standard-cli-output.adoc[CLI Output] standard (CO-1 to CO-20): default output shows only outcome, changes, decisions and the log path; failures explain themselves inline; sectioned logs, `--verbose`, `--json` / JSON Lines, per-OS log locations, prompts, exit codes, and stdout/stderr use. Listed under The Standard in the nav.
